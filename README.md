# Agenda de Contatos

Bem-vindo ao **Zerando**! 🚀

Este projeto se constitui em um site em que colocamos informações sobre pessoas que zeram (finalizam) jogos diversos. Em cada entrada, colocamos um nome, telefone (WhatsApp), jogo, e tempo para zerar.

## 🛠️ Tecnologias Utilizadas

- **HTML**: Estrutura da página.
- **CSS**: Estilização da página.
- **JavaScript**: Funcionalidade interativa.

## 🎨 Funcionalidades

- **Adicionar Contatos**: Preencha o formulário com o nome da pessoa, número do contato, jogo, e horas para zerar. Também tem um botão selecionável para caso a pessoa tenha feito 100% (Platinum Trophy).
